# The Regional-Stat System

**→ [jonoleth.github.io/ttrpg-codex](https://jonoleth.github.io/ttrpg-codex/)**

A tabletop RPG with no hit points. Six stats double as the durability of a body
region, so every landed blow lands *somewhere*, and what it costs you is
measured in what you can still do.

Every page is a single self-contained file. Nothing here needs a server — you
can download one and open it from disk, and it will work offline apart from the
web fonts, which fall back to Georgia and a system monospace. Your character is
kept in your own browser's local storage; nothing is uploaded anywhere.

## About this repository

This is generated output — the published site only. It is built from a separate
private repository that holds the design documents, the tables the pages are
compiled from, and the simulators used to test the maths. Fixes belong there,
not here; anything committed to this repo is overwritten on the next publish.
